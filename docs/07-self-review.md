## 公式資料で確認した根拠

- [Claude Code `/goal`](https://code.claude.com/docs/en/goal)：評価器は会話の出力を判定するものでファイルやテストを独立実行しない。会話が進展しない場合などは継続が停止し得る。
- [Dynamic Workflows](https://code.claude.com/docs/en/workflows)：scriptsは隔離されたJSで、ファイル操作・shell・`import()`は不可。`agent()`は`null`になる場合がある。途中停止・stall後の再試行では既存ファイル変更が残り、v2.1.305より前では完了済みagentが再実行される場合がある。
- [Subagents](https://code.claude.com/docs/en/sub-agents)：明示モデルの優先順位と、モデルallowlistによる代替、ツール権限制限を確認。
- [Desktop Cloud](https://code.claude.com/docs/en/desktop)：クラウドで複数リポジトリを選択できるが、ローカルでインストール済みのプラグインはクラウドに引き継がれない。
- [Skills](https://code.claude.com/docs/en/skills)：`--add-dir`でロードされる範囲とセッション中の変更反映制限を確認。
